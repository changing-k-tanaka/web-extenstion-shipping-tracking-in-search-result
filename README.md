# ぐぐったら配送会社追跡リンク表示

12 桁の数値の検索した場合、Google 検索結果ページに各配送会社の荷物追跡ページへのリンクを追記するブラウザ拡張

12 桁の数値の検索した場合、Google 検索結果ページに各配送会社の荷物追跡ページへのリンクを追記するブラウザ拡張です。ヤマト運輸、佐川急便、日本郵便の３つのリンクを追記します。これにより、各配送会社の荷物追跡ページにわざわざ遷移することなく荷物の現況を追跡できるようになります。

# Chrome Web Store 公開用

## 単一用途の説明

12 桁の数値の検索した場合、Google 検索結果ページに各配送会社の荷物追跡ページへのリンクを追記します。そのまま各配送会社の荷物追跡ページを開くことができます。

## ホスト権限が必要な理由
